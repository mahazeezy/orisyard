# OrisYard

Boutique bakery storefront for OrisYard (Merrillville, Indiana).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Legacy reference files

The repository still contains the original static HTML files for reference:

- `index.html`
- `menu.html`
- `cart.html`

Do not treat those as the active application.

## Provisional content

Catalog prices, policies, contact details, and reviews are centralized under `lib/` and marked provisional until business confirmation.
